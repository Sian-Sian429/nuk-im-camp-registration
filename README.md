# 國立高雄大學資管系 - 迎新活動網頁與報名系統 🚀

這是一個為 2025 高大資管系迎新活動開發的一頁式活動網站與互動式線上報名系統。

## 🛠 開發技術
* **前端**：HTML5, Bootstrap 5, JavaScript, CSS3
* **後端**：PHP (PDO)
* **資料庫**：MySQL (InfinityFree 部署)

## ✨ 專案亮點
1. **響應式一頁式設計 (RWD)**：運用 Bootstrap 5 網格系統打造，特別針對大螢幕與行動裝置優化視覺留白，實現免滾動的流暢瀏覽體驗。
2. **防呆與互動表單**：透過 HTML5 與 Bootstrap Validation 進行前端即時資料驗證，提升 UI/UX 互動體驗。
3. **安全資料庫串接**：後端採用 PHP PDO 預處理語句接收表單，有效防止 SQL Injection，並解決 utf8mb4 中文編碼問題，確保學生資料正確寫入。
